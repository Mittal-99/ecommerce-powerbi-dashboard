# E-Commerce Sales Dashboard — Power BI

## Project Overview
An end-to-end interactive Power BI dashboard built on a 
250,000-row e-commerce dataset covering customer behavior, 
product performance, and revenue trends from 2020–2024.

## Dashboard Pages
| Page | Description |
|------|-------------|
| Executive Summary | KPIs, revenue trends, payment analysis |
| Customer Analysis | Churn, age groups, gender split |
| Product Performance | Category revenue, return rates, payment matrix |

## Key Features
- Star schema data model (Fact + 4 Dimension tables)
- 15+ DAX measures including YTD, MoM Growth%, Running Total
- Conditional formatting on Return Rate % (Red/Orange/Green)
- Synced slicers across all pages
- Page navigation buttons
- Reference line benchmarking on charts

## Tech Stack
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query (M Language)
- Dataset: 250K rows, 13 columns

## Dataset
Source: ecommerce_customer_data_custom_ratios.csv
Rows: 250,000 | Columns: 13
